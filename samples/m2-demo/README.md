# M2 demo scene

A minimal project for trying the M2 renderer and the windowed fly camera.

```bash
engine run samples/m2-demo scenes/main.scene.json
```

Controls:

- `WASD` — move
- `Q` / `E` — move down / up
- `Shift` — move faster
- Hold the right mouse button — look around
- `F1` — toggle the debug overlay
- `Escape` — close

The scene contains a ground plane, a cube and an active camera.
