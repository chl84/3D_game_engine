# M3 GLB fixtures

`blender_cube.glb` and `blender_animated.glb` are original test assets created
for this repository with Blender 5.2.2 LTS. They contain no third-party models,
textures or other copyrighted material: the 4×4 checker texture is generated by
`blender/generate.py`, and the cube and empties are created by the same script.

- Author: the project authors.
- License: MIT, the same license as this repository (`LICENSE` at the root).
- Generator: `blender/generate.py` (run with `blender -b --factory-startup
  --python tests/assets/m3/blender/generate.py`).
- `blender_cube.glb`: one cube under a `Pivot` empty under a `Root` empty, with
  an embedded 4×4 PNG base-color texture and a metallic-roughness material.
- `blender_animated.glb`: the same scene plus one object-rotation animation
  channel. The M3 importer reports the channel count and does not import the
  animation data.
- `m3_basecolor.png`: the generated texture before Blender packs it into the
  GLB; kept so the authored input is reviewable.
- `texture.jpg` and `oversized.png`: solid-colour images generated with
  ImageMagick for the M3.3 decoder tests. No third-party image content; both are
  original test data under the repository MIT license.
- `normalmap.glb`: a minimal triangle with a generated flat-normal PNG and no
  TANGENT attribute, produced by `make_normalmap_glb.py`. It tests tangent
  generation during cooking. Original test data under the repository MIT
  license.

The fixtures are regenerated only when the generator script changes. The unit
tests read the checked-in files and do not require Blender.

- `blender_normal_no_tangents.glb`, `blender_normal_tangents.glb` and
  `blender_baked_normal.png`: original UV sphere and procedurally generated
  bump detail, baked to a tangent-space normal map by Blender 5.2.2 LTS
  Cycles on CPU. Generated by `blender/generate_normalmap.py`; MIT, authored
  for this project with no external model or texture inputs. Both exports use
  the same triangulated mesh and baked image; only TANGENT export differs.
  Used for CPU tangent comparison; the mirrored coupon below is the rendered golden input.

## Mirrored-UV calibration coupon

Original model authored locally with Blender 5.2.2 LTS on 2026-10-30 for this
project; license MIT, author the project authors. No external geometry,
textures, fonts or add-ons are used.

- `blender_mirrored_normalmap.blend`: editable curved coupon and beveled metal
  base, packed baked normal map, retained procedural bake-source material,
  inspection camera and two area lights. Camera/lights are not exported.
- `blender_mirrored_no_tangents.glb`: the primary M3.5 golden-test input;
  self-contained, indexed GLB with an embedded PNG and no TANGENT attributes.
- `blender_mirrored_tangents.glb`: the same geometry/UVs/materials/image with
  Blender-exported MikkTSpace tangents, for reference comparison.
- `blender_mirrored_normal.png`: 256×256, baked by Cycles on CPU from diagonal
  procedural ridges and noise into tangent-space normals. Uses Non-Color data.
- Generator: `blender/generate_mirrored_normalmap.py`.

The curved top has 1024 triangles. Its two distinct, non-overlapping UV islands
have opposite orientations: 512 positive and 512 negative triangles. Both
handedness signs occur in the exported tangents. The normal image varies in
both red and green inside each island; it is not a flat normal placeholder.
The second mesh is a simple metallic base without a normal texture.

Regenerate into a neutral temporary directory to avoid embedding personal
paths in the binary source, then copy the four output assets into this folder:

```bash
blender -b --factory-startup -noaudio -t 2 \
  --python tests/assets/m3/blender/generate_mirrored_normalmap.py \
  -- --output-dir /tmp/engine-m3-mirrored-model
```

The generator empties saved file-browser directories and uses relative paths
for both the image and its packed-file metadata. The fixture is reopenable after relocation. The source
material `Coupon_Bake_Source` preserves the procedural bake recipe; the model
uses `Coupon_Baked_Normal` for the baked result. The inspection lights/camera
are for Blender convenience, not the engine golden's authored lighting.
The M3.5 PBR golden renders this model on Linux/Windows lavapipe. M3.8 also
uses it through the public CLI/live pipeline against the same existing golden;
creating the fixture alone does not satisfy either image criterion.

Verify the delivered repository files without Blender or third-party packages:

```bash
python3 tests/assets/m3/blender/verify_mirrored_normalmap.py
```

This checks the actual GLBs and PNG in this directory: mirror orientation,
non-overlap, tangent flags/signs, embedded-image byte identity, and absence of
personal home-path markers across all four assets. The editable .blend has also
been reopened successfully after relocation with no external PNG present.

## Collapsed-position fuzz regression

`fuzz_collapsed_position_view.glb` is an exact libFuzzer mutation of this
repository's original MIT-licensed `blender_mirrored_no_tangents.glb`, captured
on 2026-10-30 during extended M3.8 fuzzing. No external input was used. SHA-256:
`7d04b891992975e95cd770623d7419b0580811580266490d6ad32c2a0470ab54`.
The original artifact name is `timeout-dabed6f070e6a08b34c1740087871b38196b0119`.
It intentionally preserves all mutated/trailing bytes for exact reproduction.

The normal-mapped primitive's POSITION accessor has no `bufferView`, producing
578 zero-initialized positions and 1024 degenerate triangles, with distinct
normals and UVs. This stresses upstream MikkTSpace's shared-vertex welding.
The initial unoptimized sanitizer run exceeded its 10-second input wall-time
budget under concurrent build load; a standalone replay completed in about
6 seconds. The adapter now uses validated non-owning buffer views in its hot
callbacks; the algorithm, source distribution, build-copy patches and time/
memory limits are unchanged. The fixture runs both as a permanent unit
regression and as an automatically seeded GLB fuzzer input. A unit pass checks
correct finite output; it does not assert a hardware-independent timing bound.

On 2026-10-31 the owner approved a deterministic asset-wide work budget for
missing-tangent generation (ADR-0015). This retained artifact now has a required
E_VALIDATION/unchanged-input expectation before MikkTSpace; the older finite-
tangent expectation is historical. Six-copy and nearby-Float32 regressions
exercise the same policy. The original file and fuzzer seeding remain intact.
